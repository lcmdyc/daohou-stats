# 道猴最爱章名决选系统

遵从直觉，两两抉择，选出你心目中最具神韵的道猴章节名。

### 在线体验入口
点击直接开始决选：**https://lcmdyc.github.io/daohou-stats/**

---

### 项目介绍
本项目为读者提供分卷章名单败淘汰决选工具，支持生成路线图与全网天梯统计。

- 完整收录全书 1~7 卷全部 266 个章节名
- 支持分卷决选与“全卷大乱斗”模式
- 决选结束可查看晋级路线图并一键导出高清 PNG 大图
- 支持将决选优胜章名计入全网喜爱度天梯榜
